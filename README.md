# Brasa Casa de Carnes — Cardápio Digital

Projeto estático otimizado para uso principal em celular e deploy na Vercel.

## Estrutura
Todos os arquivos ficam na raiz do projeto, sem subpastas e sem pasta `assets`.

- `index.html` — página principal
- `styles.css` — estilos responsivos
- `script.js` — cardápio, busca e pedido
- `logo-brasa.webp` — logo oficial
- `favicon.png` — ícone
- `frango.webp`, `suinos.webp`, `linguicas.webp`, `diversos.webp`, `espetos.webp` — imagens do catálogo
- `vercel.json` — configuração de deploy

O layout foi ajustado para telas pequenas (inclusive 320–380 px), tablets e desktop.
